Shortcuts:
ctrl + b show/hide explorer
ctrl + j show/hide terminal
ctrl + s save updates.

UNIX Commands
1. pwd (print working directory) - shows the path to the current directory.
2. ls (list) - shows the content in the current directory.
3. mkdir <dir_name> (make directory) - makes a new directory at the working directory.
4. cd <path> (change directory) - changes the working directory.
5. code <file_name.extension> - creates and opens a new file.
6. clear - clears the terminal.
